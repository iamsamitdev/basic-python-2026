### 2.1 รู้จัก uv และเหตุผลที่หลักสูตรเลือกใช้

**uv** คือเครื่องมือจัดการ Python ยุคใหม่ พัฒนาโดยบริษัท Astral (ทีมเดียวกับ Ruff) เขียนด้วยภาษา Rust จุดขายคือ **เร็วมาก** และ **รวมงานหลายอย่างไว้ในคำสั่งเดียว**

แต่เดิมการเริ่มโปรเจกต์ Python หนึ่งตัว ต้องใช้เครื่องมือหลายชิ้นประกอบกัน:

```
วิธีดั้งเดิม (หลายเครื่องมือ):            วิธีใหม่ด้วย uv (เครื่องมือเดียว):
┌───────────────────────────────┐        ┌───────────────────────────────┐
│ pyenv / ตัวติดตั้งจากเว็บ      │        │                               │
│    → ติดตั้ง Python            │        │           uv                  │
│ venv → สร้าง virtual env      │  ⟶    │  uv python install            │
│ pip  → ติดตั้งไลบรารี          │        │  uv init / uv venv            │
│ pip freeze → requirements.txt │        │  uv add / uv sync / uv lock   │
│ pip-tools → ตรึงเวอร์ชัน       │        │  uv run                       │
└───────────────────────────────┘        └───────────────────────────────┘
      จำหลายคำสั่ง ช้า ตกหล่นง่าย              คำสั่งเดียวจบ เร็วกว่ามาก
```

| ประเด็น | pip + venv (เดิม) | uv (ที่เราจะใช้) |
| --- | --- | --- |
| ความเร็วติดตั้งแพ็กเกจ | ปกติ | เร็วกว่ามาก (ระดับ 10-100 เท่าในหลายกรณี) |
| ติดตั้งตัว Python เอง | ทำไม่ได้ ต้องใช้เครื่องมืออื่น | **ทำได้ในตัว** (`uv python install`) |
| สร้าง venv | `python -m venv .venv` | `uv venv` (หรือสร้างอัตโนมัติจาก `uv run`) |
| ล็อกเวอร์ชันไลบรารี | ต้องใช้ pip-tools เสริม | **มี `uv.lock` ในตัว** |
| ไฟล์มาตรฐานโปรเจกต์ | requirements.txt (ไม่เป็นทางการ) | **pyproject.toml** (มาตรฐาน PEP 621) |
| ทำให้ทุกเครื่องเหมือนกัน | ยาก | `uv sync` คำสั่งเดียว |

> ✅ **สรุปการตัดสินใจ:** หลักสูตรนี้ใช้ uv เป็นหลัก แต่ยังสอน `pip`/`venv` ให้รู้จักด้วย (หัวข้อ 2.9) เพราะโค้ดและเอกสารเก่าจำนวนมากยังใช้อยู่ และผู้เรียนต้องอ่านออกเมื่อไปเจอในงานจริง

### 2.2 การติดตั้ง uv ลงเครื่อง

**Windows (PowerShell)** เปิด PowerShell แล้วรัน:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**macOS / Linux** เปิด Terminal แล้วรัน:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

หลังติดตั้งเสร็จ **ต้องปิด Terminal แล้วเปิดใหม่** เพื่อให้ PATH ถูกโหลดใหม่ จากนั้นตรวจสอบ:

```powershell
uv --version
```

> ⚠️ **ปัญหาที่พบบ่อยที่สุดในห้องอบรม:** ติดตั้งเสร็จแล้วพิมพ์ `uv` แล้วขึ้นว่า `'uv' is not recognized` สาเหตุเกือบ 100% คือ **ยังไม่ได้ปิด-เปิด Terminal ใหม่** ถ้าเปิดใหม่แล้วยังไม่ได้ ให้ตรวจว่ามีโฟลเดอร์ `%USERPROFILE%\.local\bin` อยู่ใน Path ของ Environment Variables หรือไม่

### 2.3 การเลือกและติดตั้งเวอร์ชันของ Python ด้วย uv

จุดเด่นที่ทำให้ uv ต่างจาก pip อย่างชัดเจนคือมันติดตั้งตัวภาษา Python ให้ได้เลย โดยไม่ต้องไปดาวน์โหลดจากเว็บไซต์

```powershell
# ดูรายการเวอร์ชันที่ติดตั้งได้และที่ติดตั้งแล้ว
uv python list

# ติดตั้ง Python 3.13 (เวอร์ชันที่ใช้ตลอดหลักสูตร)
uv python install 3.13

# ติดตั้งหลายเวอร์ชันพร้อมกันในเครื่องเดียวได้ ไม่ตีกัน
uv python install 3.12 3.14

# ดูว่าตอนนี้มีอะไรอยู่ในเครื่องบ้าง
uv python list --only-installed

# ลบเวอร์ชันที่ไม่ใช้แล้ว
uv python uninstall 3.12
```

> 💡 **ทำไมต้องมีหลายเวอร์ชันในเครื่องเดียว:** ในงานจริงคุณอาจดูแลระบบเก่าที่ตรึงไว้ที่ 3.10 พร้อมกับพัฒนาระบบใหม่บน 3.13 uv แยกเวอร์ชันให้อยู่คนละที่และให้แต่ละโปรเจกต์เลือกใช้เองผ่านไฟล์ `.python-version` โดยไม่ต้องแก้ PATH ของระบบเลย

### 2.4 การสร้างโปรเจกต์ใหม่ด้วย uv init และรู้จัก pyproject.toml

เราจะสร้างโปรเจกต์ **PyShop Mini** ที่จะใช้ต่อเนื่องตลอด 2 วัน:

```powershell
# ไปยังโฟลเดอร์ที่จะเก็บงาน (แนะนำ path ภาษาอังกฤษ ไม่มีช่องว่าง)
cd C:\PythonTraining

# สร้างโปรเจกต์ใหม่ พร้อมตรึงเวอร์ชัน Python เป็น 3.13
uv init pyshop --python 3.13

cd pyshop
```

สิ่งที่ uv สร้างให้:

```
pyshop/
├── .git/                ← uv init สร้าง git repo ให้อัตโนมัติ (ใช้ต่อใน Module 11 วันที่ 2)
├── .gitignore           ← ละเว้น .venv, __pycache__ ให้แล้ว
├── .python-version      ← ตรึงเวอร์ชัน Python ของโปรเจกต์นี้ไว้ที่ 3.13
├── README.md            ← ไฟล์อธิบายโปรเจกต์
├── main.py              ← ไฟล์โปรแกรมเริ่มต้น
└── pyproject.toml       ← ★ หัวใจของโปรเจกต์: ชื่อ เวอร์ชัน และรายการไลบรารี
```

เปิดไฟล์ `pyproject.toml` จะเห็นหน้าตาแบบนี้:

```toml
[project]
name = "pyshop"
version = "0.1.0"
description = "PyShop Mini - ระบบจัดการสินค้าคงคลังร้านค้าขนาดเล็ก (Python Basic 2026)"
readme = "README.md"
requires-python = ">=3.13"
dependencies = []
```

| บรรทัด | ความหมาย |
| --- | --- |
| `name` | ชื่อโปรเจกต์ (ใช้เมื่อเผยแพร่ขึ้น PyPI) |
| `version` | เวอร์ชันของโปรแกรมเราเอง |
| `requires-python` | เวอร์ชัน Python ขั้นต่ำที่โปรเจกต์นี้ต้องการ |
| `dependencies` | **รายการไลบรารีที่โปรเจกต์ต้องใช้** เดี๋ยว `uv add` จะมาเติมตรงนี้ให้ |

> 📖 **อ้างอิง:** รูปแบบไฟล์ `pyproject.toml` เป็นมาตรฐานกลางของ Python ตาม PEP 621 อ่านรายละเอียดได้ที่ packaging.python.org และเอกสาร uv ที่ docs.astral.sh/uv

### 2.5 Virtual Environment คืออะไร และทำไมต้องมี

**ปัญหา:** ถ้าติดตั้งไลบรารีทั้งหมดรวมกันไว้ที่เดียวในเครื่อง เมื่อโปรเจกต์ A ต้องใช้ `requests` เวอร์ชัน 2.28 แต่โปรเจกต์ B ต้องใช้ 2.31 จะเกิดการชนกัน

**ทางแก้:** แยก "กล่องไลบรารี" ของแต่ละโปรเจกต์ออกจากกัน เรียกว่า Virtual Environment

```
ไม่มี venv (ติดตั้งรวมที่เดียว):        มี venv (แยกกล่องต่อโปรเจกต์):
┌──────────────────────────┐          ┌────────────┐  ┌────────────┐
│  Python ของระบบ           │          │ Project A  │  │ Project B  │
│   requests 2.28 ← A ใช้   │          │  .venv/    │  │  .venv/    │
│   requests 2.31 ← B ใช้   │   ⟶     │  requests  │  │  requests  │
│   ❌ ทับกัน พังทั้งคู่      │          │    2.28    │  │    2.31    │
└──────────────────────────┘          └────────────┘  └────────────┘
                                        ต่างคนต่างอยู่ ลบทิ้งได้อิสระ
```

สร้าง Virtual Environment ด้วย uv:

```powershell
# สร้าง .venv ในโฟลเดอร์โปรเจกต์
uv venv

# ถ้าต้องการระบุเวอร์ชันเฉพาะ
uv venv --python 3.13
```

เทียบกับวิธีดั้งเดิม (ให้รู้จักไว้):

```powershell
# วิธีเดิม: สร้าง venv แล้วต้อง activate ก่อนใช้งานทุกครั้ง
python -m venv .venv
.\.venv\Scripts\Activate.ps1      # Windows PowerShell
source .venv/bin/activate          # macOS / Linux
```

> ✅ **จุดสำคัญที่ทำให้ uv สบายกว่า:** ถ้าใช้ `uv run` และ `uv add` คุณ **ไม่ต้อง activate เลย** uv จะหา `.venv` ของโปรเจกต์ให้เอง (และสร้างให้อัตโนมัติถ้ายังไม่มี) ซึ่งตัดปัญหาคลาสสิกที่ลืม activate แล้วไลบรารีหาไม่เจอออกไปทั้งหมด

> ⚠️ **ห้ามเอา `.venv` ขึ้น Git เด็ดขาด** เพราะมีขนาดใหญ่และผูกกับระบบปฏิบัติการของเครื่องนั้น ๆ ให้ส่ง `pyproject.toml` + `uv.lock` แทน แล้วปลายทางรัน `uv sync` (ดูหัวข้อ 6.7)

**ขั้นที่ 3 ชี้ Interpreter ไปที่ `.venv` ของ uv (ขั้นตอนที่สำคัญที่สุด)**

1. เปิดโฟลเดอร์โปรเจกต์ด้วย `code .` ใน Terminal
2. กด `Ctrl + Shift + P` พิมพ์ `Python: Select Interpreter`
3. เลือกตัวที่มีคำว่า `.venv` และ `('.venv': venv)` เช่น `.\.venv\Scripts\python.exe`
4. ดูมุมขวาล่างของ VS Code ต้องขึ้นว่า `Python 3.13.x ('.venv': venv)`

> ⚠️ **ถ้าข้ามขั้นที่ 3 จะเจออะไร:** โค้ดขึ้นขีดหยักแดงว่า `Import "xxx" could not be resolved` ทั้งที่ `uv add` ไปแล้ว เพราะ VS Code ยังมองไปที่ Python ตัวอื่นในเครื่อง ไม่ใช่ `.venv` ของโปรเจกต์ **นี่คือปัญหาที่ผู้เรียนเจอบ่อยที่สุดในหลักสูตร**

**ขั้นที่ 4 ตั้งค่าโปรเจกต์ให้เป็นระเบียบ** สร้างไฟล์ `.vscode/settings.json`:

```json
{
  "python.defaultInterpreterPath": "${workspaceFolder}/.venv/Scripts/python.exe",
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "charliermarsh.ruff",
  "editor.rulers": [88],
  "files.trimTrailingWhitespace": true,
  "[python]": {
    "editor.codeActionsOnSave": {
      "source.organizeImports": "explicit"
    }
  }
}
```

> 💡 **บน macOS/Linux** ให้เปลี่ยน path เป็น `${workspaceFolder}/.venv/bin/python`

### 2.9 pip และ venv แบบเดิม (รู้จักไว้เพื่ออ่านโค้ดเก่า)

แม้หลักสูตรนี้ใช้ uv แต่คุณจะเจอคำสั่งเหล่านี้ในเอกสารและโปรเจกต์เก่าแน่นอน จึงต้องแปลออก:

| งาน | คำสั่งเดิม (pip/venv) | คำสั่งใหม่ (uv) |

| ติดตั้งจากรายการ | `pip install -r requirements.txt` | `uv pip install -r requirements.txt` หรือ `uv sync` |

### 3.1 โครงสร้างการเขียนโปรแกรมและกฎการย่อหน้า (Indentation)

ภาษาอื่นใช้ปีกกา `{ }` กำหนดขอบเขตของบล็อกโค้ด แต่ **Python ใช้การย่อหน้าแทน** ซึ่งเป็นกฎบังคับ ไม่ใช่แค่ความสวยงาม

```python
# ถูกต้อง: ย่อหน้า 4 ช่องอย่างสม่ำเสมอ
score = 85
if score >= 80:
    grade = "A"
    print("ยินดีด้วย ได้เกรด A")
print("จบการทำงาน")   # บรรทัดนี้อยู่นอก if เพราะไม่ได้ย่อหน้า
```

```python
# ❌ ผิด: ย่อหน้าไม่สม่ำเสมอ → IndentationError
if score >= 80:
    grade = "A"
      print("ผิดแน่นอน")   # ย่อหน้าเกินมาโดยไม่มีเหตุผล
```

| กฎ | รายละเอียด |
| --- | --- |
| ใช้ **Space 4 ช่อง** ต่อ 1 ระดับ | เป็นมาตรฐาน PEP 8 (VS Code ตั้งค่าให้อัตโนมัติแล้ว) |

> ⚠️ **ข้อควรระวังกับโค้ดที่คัดลอกจากอินเทอร์เน็ต:** โค้ดจากเว็บบางแห่งใช้ Tab บางแห่งใช้ Space เมื่อวางปนกันจะเกิด `TabError: inconsistent use of tabs and spaces` วิธีแก้เร็วที่สุดใน VS Code คือกด `Ctrl + Shift + P` → `Convert Indentation to Spaces`

### 3.2 ตัวแปร การกำหนดค่า และชนิดข้อมูลพื้นฐาน

ใน Python การสร้างตัวแปรคือการ "ผูกชื่อเข้ากับค่า" ไม่ต้องประกาศชนิดข้อมูลล่วงหน้า

```python
# ชนิดข้อมูลพื้นฐาน 4 ชนิดที่ต้องรู้จัก
product_name = "แป้นพิมพ์ไร้สาย"   # str   - ข้อความ
price = 890.50                     # float - ทศนิยม
stock = 25                         # int   - จำนวนเต็ม
is_active = True                   # bool  - จริง/เท็จ

# ตรวจสอบชนิดข้อมูลด้วย type()
print(type(product_name))   # <class 'str'>
print(type(price))          # <class 'float'>
print(type(stock))          # <class 'int'>
print(type(is_active))      # <class 'bool'>
```

| ชนิด | ตัวอย่างค่า | ใช้เก็บอะไร | ข้อควรระวัง |
| --- | --- | --- | --- |
| `int` | `25`, `-3`, `1_000_000` | จำนวนเต็ม ไม่จำกัดขนาด | ใช้ `_` คั่นหลักได้เพื่ออ่านง่าย |
| `float` | `890.50`, `3.14`, `2e3` | ทศนิยม | มีความคลาดเคลื่อน เช่น `0.1 + 0.2 != 0.3` |
| `str` | `"สวัสดี"`, `'A'` | ข้อความ | ใช้ `'` หรือ `"` ก็ได้ แต่ต้องเปิด-ปิดชนิดเดียวกัน |
| `bool` | `True`, `False` | ค่าตรรกะ | ต้องขึ้นต้นด้วยตัวใหญ่เสมอ |
| `None` | `None` | "ยังไม่มีค่า" | ต่างจาก `0` และ `""` |

**การแปลงชนิดข้อมูล (Type Casting)**

```python
qty_text = "12"
qty = int(qty_text)          # str → int   = 12
price = float("890.50")      # str → float = 890.5
label = str(25)              # int → str   = "25"
flag = bool(0)               # int → bool  = False

# ⚠️ ระวัง: แปลงข้อความที่ไม่ใช่ตัวเลขจะเกิด ValueError
# int("12 ชิ้น")  →  ValueError: invalid literal for int() with base 10
```

> 💡 **ค่าที่ Python ถือว่าเป็น `False` (Falsy):** `0`, `0.0`, `""`, `[]`, `{}`, `()`, `set()`, `None` และ `False` นอกนั้นเป็น `True` ทั้งหมด ความรู้นี้ใช้เขียน `if not items:` แทน `if len(items) == 0:` ได้กระชับกว่า

### 3.3 การรับค่าจากผู้ใช้และการแสดงผลด้วย f-string

```python
# input() คืนค่าเป็น str เสมอ ต้องแปลงเองถ้าจะคำนวณ
name = input("กรุณาใส่ชื่อสินค้า: ")
price = float(input("ราคาต่อชิ้น: "))
qty = int(input("จำนวน: "))

total = price * qty
```

**f-string คือมาตรฐานการแสดงผลของ Python ยุคใหม่** (ใช้ได้ตั้งแต่ 3.6 ขึ้นไป)

```python
# ✅ f-string: อ่านง่ายที่สุด และเร็วที่สุด (แนะนำใช้เสมอ)
print(f"สินค้า {name} จำนวน {qty} ชิ้น รวม {total:,.2f} บาท")

# วิธีเก่าที่ยังพบในโค้ดเดิม (รู้จักไว้พอ)
print("สินค้า {} จำนวน {} ชิ้น".format(name, qty))   # .format()
print("สินค้า %s จำนวน %d ชิ้น" % (name, qty))       # %-formatting (เก่ามาก)
```

**รูปแบบการจัดหน้าใน f-string ที่ใช้บ่อยที่สุด**

```python
price = 1234567.891
name = "เมาส์"
ratio = 0.1875

print(f"{price:,.2f}")      # 1,234,567.89   ← คั่นหลักพัน ทศนิยม 2 ตำแหน่ง
print(f"{price:>15,.2f}")   #    1,234,567.89 ← ชิดขวา กว้าง 15
print(f"{name:<10}|")       # เมาส์      |    ← ชิดซ้าย กว้าง 10
print(f"{name:^10}|")       #   เมาส์    |    ← กึ่งกลาง
print(f"{ratio:.1%}")       # 18.8%           ← แสดงเป็นเปอร์เซ็นต์
print(f"{255:04d}")         # 0255            ← เติมศูนย์ข้างหน้า
print(f"{price = }")        # price = 1234567.891  ← ดีบักเร็ว (Python 3.8+)
```

> 💡 **เคล็ดลับดีบัก:** `f"{ตัวแปร = }"` จะพิมพ์ทั้งชื่อตัวแปรและค่าออกมาให้เลย เหมาะกับการตรวจค่ากลางทางโดยไม่ต้องพิมพ์ชื่อซ้ำสองรอบ

### 3.4 นิพจน์ ตัวดำเนินการ และตัวถูกดำเนินการ

**ตัวดำเนินการทางคณิตศาสตร์**

```python
a, b = 17, 5

print(a + b)    # 22   บวก
print(a - b)    # 12   ลบ
print(a * b)    # 85   คูณ
print(a / b)    # 3.4  หาร (ได้ float เสมอ)
print(a // b)   # 3    หารปัดเศษลง (Floor Division)
print(a % b)    # 2    เศษจากการหาร (Modulus)
print(a ** b)   # 1419857  ยกกำลัง
```

> 💡 **`%` ใช้ทำอะไรในงานจริง:** ตรวจเลขคู่/คี่ (`n % 2 == 0`), แบ่งกลุ่มวนรอบ, ตรวจว่าครบทุก N รอบหรือยัง (`if i % 100 == 0:` แล้วรายงานความคืบหน้า)

**ตัวดำเนินการเปรียบเทียบและตรรกะ**

```python
stock = 5
price = 890

print(stock > 0)                      # True
print(stock == 5 and price < 1000)    # True   ต้องจริงทั้งคู่
print(stock > 10 or price < 1000)     # True   จริงอย่างน้อยหนึ่ง
print(not stock > 0)                  # False  กลับค่า

# Python เขียนช่วงค่าต่อกันได้ตรง ๆ (ภาษาอื่นทำไม่ได้)
print(0 < stock <= 10)                # True
```

| กลุ่ม | ตัวดำเนินการ | ความหมาย |
| --- | --- | --- |
| เปรียบเทียบ | `==`, `!=`, `>`, `<`, `>=`, `<=` | คืนค่า `True`/`False` |
| ตรรกะ | `and`, `or`, `not` | เชื่อมเงื่อนไข |
| สมาชิก | `in`, `not in` | ตรวจว่าอยู่ในลำดับหรือไม่ |
| เอกลักษณ์ | `is`, `is not` | ตรวจว่าเป็นวัตถุเดียวกันหรือไม่ |
| กำหนดค่าย่อ | `+=`, `-=`, `*=`, `/=`, `//=` | `x += 1` เท่ากับ `x = x + 1` |

> ⚠️ **`==` กับ `is` ต่างกันอย่างไร:** `==` เทียบ **ค่า** ส่วน `is` เทียบว่าเป็น **วัตถุตัวเดียวกันในหน่วยความจำ** หรือไม่ กฎง่าย ๆ คือ ใช้ `is` เฉพาะกับ `None`, `True`, `False` เท่านั้น (`if value is None:`) นอกนั้นใช้ `==`

**การดำเนินการกับข้อความ (String)**

```python
name = "  Wireless Keyboard  "

print(name.strip())            # "Wireless Keyboard"  ตัดช่องว่างหัวท้าย
print(name.strip().upper())    # "WIRELESS KEYBOARD"
print(name.strip().lower())    # "wireless keyboard"

print("A-B-C".split("-"))               # ['A', 'B', 'C']
print(", ".join(["เมาส์", "คีย์บอร์ด"]))  # "เมาส์, คีย์บอร์ด"

# การตัดข้อความ (Slicing) ใช้หลักเดียวกับ List ในหัวข้อ 4.1
code = "PRD-2026-0042"
print(code[:3])       # "PRD"
print(code[-4:])      # "0042"
```

### 3.5 เงื่อนไข การตัดสินใจ และการควบคุมทิศทาง

```python
stock = int(input("จำนวนคงเหลือ: "))

if stock <= 0:
    status = "สินค้าหมด"
```

```
ลำดับการตรวจเงื่อนไข if/elif/else:

           │ ไม่                              │
      stock < 10 ?  ──ใช่──▶ "ใกล้หมด"    ──┤

  ★ เมื่อเจอเงื่อนไขแรกที่เป็นจริง จะข้ามที่เหลือทั้งหมดทันที
```

**เงื่อนไขแบบบรรทัดเดียว (Conditional Expression)**

```python
# เหมาะกับเงื่อนไขสั้น ๆ เท่านั้น ถ้ายาวกว่านี้ให้ใช้ if ปกติเพื่อความอ่านง่าย
label = "มีสินค้า" if stock > 0 else "หมด"
```

**`match-case` (Structural Pattern Matching, Python 3.10 ขึ้นไป)**

```python
command = input("เลือกเมนู (add/list/report/exit): ").strip().lower()

match command:
    case "add":
        print("→ เพิ่มสินค้าใหม่")
    case "list":
        print("→ แสดงรายการสินค้าทั้งหมด")
    case "report" | "summary":        # จับได้หลายค่าด้วย |
        print("→ สรุปรายงาน")
    case "exit" | "quit":
        print("→ ออกจากโปรแกรม")
    case _:                            # _ คือกรณีอื่น ๆ ทั้งหมด (ค่าเริ่มต้น)
        print(f"ไม่รู้จักคำสั่ง '{command}'")
```

| ใช้ `if/elif` เมื่อ | ใช้ `match-case` เมื่อ |
| --- | --- |
| เงื่อนไขเป็นช่วงค่าหรือการเปรียบเทียบ (`x > 10`) | เทียบกับ **ค่าที่แน่นอน** หลายค่า เช่น เมนูคำสั่ง |
| มีเงื่อนไขซับซ้อนผสม and/or | ต้องการแยกโครงสร้างข้อมูล (เช่น tuple, dict) |
| ต้องรองรับ Python เก่ากว่า 3.10 | ใช้ Python 3.10 ขึ้นไปแน่นอน |

### 3.6 การทำซ้ำด้วย for และ while

**`for` ใช้เมื่อรู้ว่าต้องวนกี่รอบ หรือวนตามข้อมูลที่มีอยู่**

```python
# วนตามลำดับตัวเลข
for i in range(5):            # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):         # 1 ถึง 5
    print(i)

for i in range(0, 101, 10):   # 0, 10, 20, ..., 100 (ก้าวทีละ 10)
    print(i)

for i in range(5, 0, -1):     # 5, 4, 3, 2, 1 (นับถอยหลัง)
    print(i)

# วนตามรายการข้อมูล (ใช้บ่อยที่สุดในงานจริง)
products = ["เมาส์", "คีย์บอร์ด", "จอภาพ"]
for product in products:
    print(f"- {product}")

# ต้องการเลขลำดับด้วย ใช้ enumerate (ไม่ต้องสร้างตัวนับเอง)
for index, product in enumerate(products, start=1):
    print(f"{index}. {product}")

# วนสองรายการพร้อมกันด้วย zip
prices = [590, 890, 4500]
for product, price in zip(products, prices):
    print(f"{product:<12} {price:>8,} บาท")
```

**`while` ใช้เมื่อไม่รู้จำนวนรอบล่วงหน้า แต่รู้เงื่อนไขที่จะหยุด**

```python
total = 0
while True:
    text = input("ใส่ราคาสินค้า (พิมพ์ q เพื่อจบ): ")
    if text.lower() == "q":
        break                    # ออกจากลูปทันที
    if not text.replace(".", "", 1).isdigit():
        print("  ⚠ กรุณาใส่ตัวเลขเท่านั้น")
        continue                 # ข้ามไปเริ่มรอบใหม่
    total += float(text)

print(f"ยอดรวมทั้งสิ้น {total:,.2f} บาท")
```

| คำสั่ง | ผลที่เกิด |
| --- | --- |
| `break` | ออกจากลูปทันที ไม่ทำรอบที่เหลือ |
| `continue` | ข้ามคำสั่งที่เหลือในรอบนี้ ไปเริ่มรอบถัดไป |
| `else` ของลูป | ทำงานเมื่อลูปจบ **โดยไม่โดน `break`** (ใช้ตรวจว่า "หาไม่เจอ") |
| `pass` | ไม่ทำอะไร ใช้เป็นที่กันตำแหน่งไว้ก่อน |

```python
# for...else - ใช้ตรวจว่า "วนจนจบแล้วยังไม่เจอ"
target = "จอภาพ"
for product in products:
    if product == target:
        print(f"พบ {target} ในรายการ")
        break
else:
    print(f"ไม่พบ {target} ในรายการ")
```

> ⚠️ **กับดัก Infinite Loop:** `while` ที่ไม่มีทางทำให้เงื่อนไขเป็นเท็จ และไม่มี `break` จะวนไม่รู้จบ ถ้าเผลอรันไปแล้วให้กด `Ctrl + C` ใน Terminal เพื่อหยุด

### 3.7 การเขียน Comment และมาตรฐาน PEP 8

```python
# นี่คือคอมเมนต์บรรทัดเดียว อธิบาย "ทำไม" ไม่ใช่ "ทำอะไร"

# ❌ คอมเมนต์ที่ไม่มีประโยชน์ (โค้ดบอกอยู่แล้ว)
total = price * qty   # คูณราคากับจำนวน

# ✅ คอมเมนต์ที่มีประโยชน์ (บอกเหตุผลที่โค้ดไม่ได้บอก)
total = price * qty * 1.07   # รวม VAT 7% ตามข้อกำหนดของฝ่ายบัญชี
```

**สรุปกฎ PEP 8 ที่ใช้บ่อยที่สุด**

| หัวข้อ | มาตรฐาน | ตัวอย่าง |
| --- | --- | --- |
| ชื่อตัวแปร/ฟังก์ชัน | `snake_case` | `product_name`, `calculate_total()` |
| ชื่อคลาส | `PascalCase` | `ProductManager` |

### 🧪 Workshop 3.1 - โปรแกรมคำนวณและตรวจสอบเงื่อนไขสต็อกสินค้า

> **เป้าหมาย:** รวมทุกอย่างใน Module 3 (ตัวแปร, input, f-string, เงื่อนไข, ลูป) เป็นโปรแกรมที่ใช้ได้จริงหนึ่งตัว

**โจทย์:** เขียนโปรแกรมรับรายการสินค้าเข้ามาทีละรายการ คำนวณยอดรวมพร้อม VAT และแจ้งเตือนสถานะสต็อก

**ไฟล์ `workshop3.py`**

```python
"""Workshop 3.1 - เครื่องคิดเลขสต็อกสินค้าของ PyShop Mini"""

VAT_RATE = 0.07
LOW_STOCK_LIMIT = 10


def main() -> None:
    print("=" * 50)
    print("  PyShop Mini - ตรวจสอบสต็อกและคำนวณมูลค่า")
    print("=" * 50)

    grand_total = 0.0
    item_count = 0

    while True:
        name = input("\nชื่อสินค้า (Enter ว่างเพื่อจบ): ").strip()
        if name == "":
            break

        # รับราคา พร้อมตรวจความถูกต้องแบบง่าย
        price_text = input("ราคาต่อชิ้น: ").strip()
        qty_text = input("จำนวนคงเหลือ: ").strip()

        if not price_text.replace(".", "", 1).isdigit() or not qty_text.isdigit():
            print("  ⚠ ราคาและจำนวนต้องเป็นตัวเลขเท่านั้น ข้ามรายการนี้")
            continue

        price = float(price_text)
        qty = int(qty_text)
        subtotal = price * qty

        # ตรวจสถานะสต็อก
        if qty == 0:
            status = "❌ สินค้าหมด"
        elif qty < LOW_STOCK_LIMIT:
            status = "⚠️ ใกล้หมด ควรสั่งเพิ่ม"
        else:
            status = "✅ ปกติ"

        print(f"  {name:<20} {price:>10,.2f} x {qty:>3} = {subtotal:>12,.2f} บาท")
        print(f"  สถานะ: {status}")

        grand_total += subtotal
        item_count += 1

    # สรุปผลรวม
    print("\n" + "=" * 50)
    if item_count == 0:
        print("  ไม่มีรายการสินค้า")
        return

    vat = grand_total * VAT_RATE
    print(f"  จำนวนรายการ      : {item_count:>15,} รายการ")
    print(f"  มูลค่ารวม         : {grand_total:>15,.2f} บาท")
    print(f"  VAT {VAT_RATE:.0%}          : {vat:>15,.2f} บาท")
    print(f"  รวมทั้งสิ้น       : {grand_total + vat:>15,.2f} บาท")
    print("=" * 50)


if __name__ == "__main__":
    main()
```

### 4.4 Dictionary - ข้อมูลแบบ Key-Value

Dictionary คือชนิดข้อมูลที่ใช้บ่อยที่สุดในงานจริง เพราะเก็บข้อมูลที่มี "ชื่อฟิลด์" ได้ตรงไปตรงมา

```python
product = {
    "code": "PRD-001",
    "name": "เมาส์ไร้สาย",
    "price": 890.0,
    "stock": 25,
    "tags": ["อุปกรณ์เสริม", "ไร้สาย"],
}

# --- อ่านค่า ---
print(product["name"])                    # "เมาส์ไร้สาย"
print(product.get("brand"))               # None (ไม่พังแม้ไม่มี key)
print(product.get("brand", "ไม่ระบุ"))     # "ไม่ระบุ" (กำหนดค่าสำรอง)
# print(product["brand"])                 # ❌ KeyError

# --- เพิ่ม / แก้ไข ---
product["brand"] = "Logitech"             # เพิ่ม key ใหม่
product["stock"] = 30                     # แก้ไขค่าเดิม
product.update({"price": 850.0, "color": "ดำ"})   # แก้/เพิ่มหลายตัวพร้อมกัน

# --- ลบ ---
removed = product.pop("color")            # ลบและคืนค่าที่ลบ
del product["brand"]                      # ลบตรง ๆ

# --- ตรวจสอบ ---
print("price" in product)                 # True  (ตรวจที่ key)
print(len(product))                       # จำนวน key ทั้งหมด
```

**การวนลูปอ่านข้อมูล**

```python
# วน key อย่างเดียว
for key in product:
    print(key)

# วน value อย่างเดียว
for value in product.values():
    print(value)

# ★ วนทั้ง key และ value พร้อมกัน (ใช้บ่อยที่สุด)
for key, value in product.items():
    print(f"{key:<8}: {value}")
```

**Dictionary ซ้อน List - โครงสร้างข้อมูลจริงที่จะใช้ตลอดหลักสูตร**

```python
inventory = [
    {"code": "PRD-001", "name": "เมาส์ไร้สาย",  "price": 890,  "stock": 25},
    {"code": "PRD-002", "name": "คีย์บอร์ด",    "price": 1290, "stock": 8},

    {"code": "PRD-004", "name": "หูฟัง",        "price": 1590, "stock": 42},
]

# แสดงเป็นตาราง
print(f"{'รหัส':<10}{'ชื่อสินค้า':<18}{'ราคา':>10}{'คงเหลือ':>10}")
```

### 4.5 List Comprehension - เขียนโค้ดให้กระชับ

```python
inventory = [
    {"code": "PRD-001", "name": "เมาส์ไร้สาย",   "price": 890,  "stock": 25, "category": "อุปกรณ์เสริม"},
    {"code": "PRD-002", "name": "คีย์บอร์ด",     "price": 1290, "stock": 8,  "category": "อุปกรณ์เสริม"},
    {"code": "PRD-003", "name": "จอภาพ 27 นิ้ว", "price": 6900, "stock": 0,  "category": "จอแสดงผล"},
    {"code": "PRD-004", "name": "หูฟัง",         "price": 1590, "stock": 42, "category": "เสียง"},
    {"code": "PRD-005", "name": "ลำโพง",         "price": 2490, "stock": 5,  "category": "เสียง"},
]

LOW_STOCK_LIMIT = 10


def main() -> None:
    # 1) ตารางรายการสินค้าทั้งหมด
    print("=" * 62)
    print(f"{'รหัส':<10}{'ชื่อสินค้า':<18}{'ราคา':>10}{'คงเหลือ':>10}{'มูลค่า':>14}")
    print("-" * 62)
    for item in inventory:
        value = item["price"] * item["stock"]
        print(
            f"{item['code']:<10}{item['name']:<18}"
            f"{item['price']:>10,}{item['stock']:>10}{value:>14,}"
        )

    # 2) สรุปภาพรวมด้วย Comprehension
    total_value = sum(i["price"] * i["stock"] for i in inventory)
    total_qty = sum(i["stock"] for i in inventory)
    avg_price = sum(i["price"] for i in inventory) / len(inventory)

    print("-" * 62)
    print(f"{'รวม':<38}{total_qty:>10}{total_value:>14,}")
    print(f"ราคาเฉลี่ยต่อรายการ: {avg_price:,.2f} บาท")

    # 3) หมวดหมู่ทั้งหมด (Set ตัดค่าซ้ำ)
    categories = {i["category"] for i in inventory}
    print(f"\nหมวดหมู่ทั้งหมด ({len(categories)}): {', '.join(sorted(categories))}")

    # 4) สินค้าที่ต้องสั่งเพิ่ม (List Comprehension + เงื่อนไข)
    low_stock = [i for i in inventory if 0 < i["stock"] < LOW_STOCK_LIMIT]
    out_of_stock = [i["name"] for i in inventory if i["stock"] == 0]

    print("\n⚠️  สินค้าใกล้หมด (น้อยกว่า 10 ชิ้น):")
    for item in low_stock:
        print(f"   - {item['name']} เหลือ {item['stock']} ชิ้น")

    print("\n❌ สินค้าหมด:")
    print(f"   {', '.join(out_of_stock) if out_of_stock else '- ไม่มี -'}")

    # 5) สรุปมูลค่าแยกตามหมวดหมู่ (Dict สะสมค่า)
    value_by_category: dict[str, int] = {}
    for item in inventory:
        cat = item["category"]
        value_by_category[cat] = value_by_category.get(cat, 0) + item["price"] * item["stock"]

    print("\n📊 มูลค่าคลังแยกตามหมวดหมู่:")
    for cat, value in sorted(value_by_category.items(), key=lambda x: x[1], reverse=True):
        share = value / total_value * 100 if total_value else 0
        bar = "█" * int(share / 4)
        print(f"   {cat:<14}{value:>10,} บาท  {share:>5.1f}%  {bar}")

    # 6) สินค้าราคาสูงสุด / ต่ำสุด
    most_expensive = max(inventory, key=lambda i: i["price"])
    cheapest = min(inventory, key=lambda i: i["price"])
    print(f"\nแพงที่สุด : {most_expensive['name']} ({most_expensive['price']:,} บาท)")
    print(f"ถูกที่สุด : {cheapest['name']} ({cheapest['price']:,} บาท)")


if __name__ == "__main__":
    main()
```

### 5.5 Docstring และ Type Hints

**Docstring** คือคำอธิบายฟังก์ชันที่อยู่ในโค้ด อ่านได้ผ่าน `help()` และ Editor จะแสดงให้ตอนเลื่อนเมาส์ไปวาง

```python
def calculate_total(price: float, qty: int, vat_rate: float = 0.07) -> float:
    """คำนวณราคารวมสินค้าพร้อมภาษีมูลค่าเพิ่ม

    Args:
        price: ราคาต่อหน่วย (บาท) ต้องไม่ติดลบ
        qty: จำนวนชิ้น ต้องเป็นจำนวนเต็มบวก
        vat_rate: อัตราภาษี ค่าเริ่มต้น 0.07 (7%)

    Returns:
        ราคารวมหลังบวก VAT แล้ว (บาท)

    Raises:
        ValueError: เมื่อ price หรือ qty ติดลบ

    Examples:
        >>> calculate_total(100, 2)
        214.0
    """
    if price < 0 or qty < 0:
        raise ValueError("ราคาและจำนวนต้องไม่ติดลบ")
    return price * qty * (1 + vat_rate)


help(calculate_total)      # แสดง docstring ทั้งหมด
```

**Type Hints** คือการระบุชนิดข้อมูลที่คาดหวัง เขียนแล้วได้ประโยชน์ทันที 3 อย่าง

```python
# ไม่มี Type Hint - เดาไม่ออกว่าต้องส่งอะไร
def process(data, config):
    ...

# ✅ มี Type Hint - อ่านปุ๊บรู้ปั๊บ
def process(data: list[dict], config: dict[str, str]) -> list[dict]:
    ...
```

| ชนิด | เขียนแบบ | ตัวอย่าง |
| --- | --- | --- |
| พื้นฐาน | `int`, `float`, `str`, `bool` | `def f(x: int) -> str:` |
| ลิสต์ | `list[ชนิด]` | `list[str]`, `list[dict]` |
| ดิกชันนารี | `dict[คีย์, ค่า]` | `dict[str, float]` |
| ทูเพิล | `tuple[ชนิด, ...]` | `tuple[int, int]` |
| อาจเป็น None ได้ | `ชนิด \| None` | `str \| None` |
| หลายชนิดได้ | `ชนิดA \| ชนิดB` | `int \| float` |
| ไม่คืนค่า | `-> None` | `def show() -> None:` |

> 💡 **สำคัญ:** Type Hints **ไม่บังคับตอนรัน** Python จะไม่ error ถ้าส่งผิดชนิด แต่ประโยชน์คือ (1) Pylance ใน VS Code จะขีดเส้นเตือนให้ทันที (2) เพื่อนร่วมทีมอ่านโค้ดเข้าใจเร็วขึ้น (3) เครื่องมืออย่าง `mypy` ตรวจสอบให้ได้ก่อนรันจริง

```python
# เรียงตามราคาจากมากไปน้อย
by_price = sorted(inventory, key=lambda item: item["price"], reverse=True)

# เรียงตามมูลค่าคงคลัง
by_value = sorted(inventory, key=lambda i: i["price"] * i["stock"], reverse=True)

# เรียงหลายเงื่อนไข (สต็อกมากก่อน ถ้าเท่ากันเรียงตามชื่อ)
by_multi = sorted(inventory, key=lambda i: (-i["stock"], i["name"]))

# ใช้กับ filter และ map (แต่ Comprehension อ่านง่ายกว่า)
available = list(filter(lambda i: i["stock"] > 0, inventory))
names = list(map(lambda i: i["name"], inventory))

# ✅ เขียนแบบ Comprehension อ่านง่ายกว่า แนะนำแบบนี้
available = [i for i in inventory if i["stock"] > 0]
names = [i["name"] for i in inventory]
```

> ⚠️ **กฎการใช้ Lambda:** ใช้เมื่อเป็นนิพจน์สั้น ๆ ที่ใช้ครั้งเดียวเท่านั้น (โดยเฉพาะกับ `key=`) ถ้ามีตรรกะยาวกว่าหนึ่งบรรทัดหรือใช้ซ้ำ ให้เขียนเป็น `def` ที่มีชื่อจะดีกว่าเสมอ เพราะตั้งชื่อสื่อความหมายได้และดีบักง่ายกว่า

### 🧪 Workshop 5.1 - แปลงโค้ดที่เขียนซ้ำให้เป็นฟังก์ชัน

> **เป้าหมาย:** Refactor โค้ดจาก Workshop 4.1 ให้เป็นฟังก์ชันที่นำกลับมาใช้ใหม่ได้ พร้อม Type Hints และ Docstring ครบ ซึ่งจะกลายเป็นแกนของ PyShop Mini

**ไฟล์ `workshop5.py`**

```python
"""Workshop 5.1 - แยกตรรกะของ PyShop Mini ออกเป็นฟังก์ชัน"""

VAT_RATE = 0.07
LOW_STOCK_LIMIT = 10

Product = dict[str, str | int | float]   # ตั้งชื่อเล่นให้ชนิดข้อมูล อ่านง่ายขึ้น


def create_product(
    code: str, name: str, price: float, stock: int = 0, category: str = "ทั่วไป"
) -> Product:
    """สร้างข้อมูลสินค้า 1 รายการในรูปแบบมาตรฐานของระบบ"""
    return {
        "code": code,
        "name": name,
        "price": price,
        "stock": stock,
        "category": category,
    }


def stock_value(product: Product) -> float:
    """คืนมูลค่าคงคลังของสินค้า 1 รายการ (ราคา x จำนวน)"""
    return product["price"] * product["stock"]


def total_stock_value(products: list[Product]) -> float:
    """คืนมูลค่าคงคลังรวมของสินค้าทั้งหมด"""
    return sum(stock_value(p) for p in products)


def add_vat(amount: float, rate: float = VAT_RATE) -> float:
    """บวกภาษีมูลค่าเพิ่มเข้ากับยอดเงินที่ระบุ"""
    return amount * (1 + rate)


def stock_status(product: Product) -> str:
    """แปลจำนวนคงเหลือเป็นข้อความสถานะที่ผู้ใช้อ่านเข้าใจ"""
    stock = product["stock"]
    if stock <= 0:
        return "สินค้าหมด"
    if stock < LOW_STOCK_LIMIT:
        return "ใกล้หมด"
    return "ปกติ"


def find_products(products: list[Product], keyword: str) -> list[Product]:
    """ค้นหาสินค้าจากคำค้นหา (ตรวจทั้งรหัสและชื่อ ไม่สนตัวพิมพ์ใหญ่เล็ก)"""
    key = keyword.strip().lower()
    if not key:
        return list(products)
    return [
        p for p in products
        if key in p["name"].lower() or key in p["code"].lower()
    ]


def format_row(product: Product) -> str:
    """จัดรูปแบบสินค้า 1 รายการให้เป็นบรรทัดในตาราง"""
    return (
        f"{product['code']:<10}{product['name']:<18}"
        f"{product['price']:>10,.0f}{product['stock']:>9}"
        f"  {stock_status(product)}"
    )


def print_table(products: list[Product], title: str = "รายการสินค้า") -> None:
    """แสดงตารางสินค้าพร้อมหัวตารางและยอดสรุปท้ายตาราง"""
    print(f"\n{title}")
    print("=" * 62)
    print(f"{'รหัส':<10}{'ชื่อสินค้า':<18}{'ราคา':>10}{'คงเหลือ':>9}  สถานะ")
    print("-" * 62)

    if not products:
        print("  - ไม่พบข้อมูล -")
        return

    for product in products:
        print(format_row(product))

    value = total_stock_value(products)
    print("-" * 62)
    print(f"มูลค่ารวม {value:>18,.2f} บาท (รวม VAT {add_vat(value):,.2f} บาท)")


def main() -> None:
    inventory = [
        create_product("PRD-001", "เมาส์ไร้สาย", 890, 25, "อุปกรณ์เสริม"),
        create_product("PRD-002", "คีย์บอร์ด", 1290, 8, "อุปกรณ์เสริม"),
        create_product("PRD-003", "จอภาพ 27 นิ้ว", 6900, 0, "จอแสดงผล"),
        create_product("PRD-004", "หูฟัง", 1590, 42, "เสียง"),
        create_product("PRD-005", "ลำโพง", 2490, 5, "เสียง"),
    ]

    print_table(inventory, "📦 สินค้าทั้งหมด")

    low = [p for p in inventory if stock_status(p) != "ปกติ"]
    print_table(low, "⚠️  สินค้าที่ต้องสั่งเพิ่ม")

    keyword = input("\nค้นหาสินค้า (Enter เพื่อข้าม): ")
    print_table(find_products(inventory, keyword), f"🔍 ผลการค้นหา '{keyword}'")


if __name__ == "__main__":
    main()
```

> ✅ **ผลลัพธ์ที่คาดหวัง:** เห็นตาราง 3 ชุด (ทั้งหมด / ต้องสั่งเพิ่ม / ผลค้นหา) โดยใช้ฟังก์ชัน `print_table()` ตัวเดียวกันทั้งสามครั้ง **นี่คือหัวใจของ Module 5** คือเขียนครั้งเดียวใช้ได้หลายที่
>

### 6.1 การสร้างโมดูล (Module) ใน Python

**โมดูลคือไฟล์ `.py` หนึ่งไฟล์** เท่านั้นเอง ไม่มีอะไรพิเศษกว่านั้น

สร้างไฟล์ `pricing.py`:

```python
"""pricing.py - โมดูลรวมตรรกะเกี่ยวกับราคาของ PyShop Mini"""

VAT_RATE = 0.07


def add_vat(amount: float, rate: float = VAT_RATE) -> float:
    """บวก VAT เข้ากับยอดเงิน"""
    return amount * (1 + rate)


def apply_discount(price: float, percent: float) -> float:
    """คำนวณราคาหลังหักส่วนลดเป็นเปอร์เซ็นต์"""
    if not 0 <= percent <= 100:
        return price
    return price * (1 - percent / 100)


# บล็อกนี้ทำงานเฉพาะเมื่อรันไฟล์นี้ตรง ๆ ไม่ทำงานตอนถูก import
if __name__ == "__main__":
    print(add_vat(1000))          # 1070.0
    print(apply_discount(1000, 10))   # 900.0
```

> ✅ **`if __name__ == "__main__":` คืออะไรและทำไมต้องมี:** เมื่อรันไฟล์ตรง ๆ Python จะตั้งค่าตัวแปรพิเศษ `__name__` เป็น `"__main__"` แต่เมื่อไฟล์ถูก `import` ค่าจะเป็นชื่อโมดูลแทน บล็อกนี้จึงเป็นวิธีแยก "โค้ดทดสอบ" ออกจาก "โค้ดที่ให้คนอื่นใช้" ถ้าไม่ใส่ ทุกครั้งที่คนอื่น import ไฟล์เรา โค้ดทดสอบจะรันขึ้นมาเองแบบไม่ตั้งใจ

### 6.2 การเรียกใช้งานโมดูล

```python
# 1) import ทั้งโมดูล (ปลอดภัยที่สุด รู้ที่มาชัดเจน)
import pricing
print(pricing.add_vat(1000))
print(pricing.VAT_RATE)

# 2) from-import เฉพาะสิ่งที่ต้องการ (เขียนสั้นกว่า)
from pricing import add_vat, VAT_RATE
print(add_vat(1000))

# 3) as - ตั้งชื่อเล่น (ใช้มากกับไลบรารีชื่อยาว)

print(pr.add_vat(1000))

# ตัวอย่างที่พบบ่อยในสาย Data
# import pandas as pd
# import numpy as np

# 4) ❌ import ทุกอย่าง - หลีกเลี่ยงเด็ดขาด

```

| รูปแบบ | ข้อดี | ข้อเสีย |
| --- | --- | --- |
| `import module` | รู้ที่มาชัดเจนเมื่ออ่านโค้ด | พิมพ์ยาว |
| `from module import name` | เรียกสั้น | ถ้ามีชื่อซ้ำจากหลายโมดูลจะสับสน |
| `import module as m` | สั้นแต่ยังรู้ที่มา | ต้องจำชื่อย่อ |
| `from module import *` | (ไม่มีข้อดีที่ควรแลก) | ชื่อทับกันโดยไม่รู้ตัว หา bug ยาก |

### 6.3 แพ็คเกจ (Package) และการจัดโครงสร้างโปรเจกต์

**Package คือโฟลเดอร์ที่รวมหลายโมดูลไว้ด้วยกัน** โดยมีไฟล์ `__init__.py` เป็นตัวบอกว่าโฟลเดอร์นี้เป็น Package

```
pyshop/
├── pyproject.toml
├── main.py                    ← จุดเริ่มโปรแกรม
└── src/
    └── pyshop/                ← Package หลัก
        ├── __init__.py        ← ทำให้โฟลเดอร์นี้เป็น package
        ├── models.py          ← โครงสร้างข้อมูลสินค้า
        ├── pricing.py         ← ตรรกะการคำนวณราคา
        ├── inventory.py       ← ตรรกะการจัดการคลัง
        └── report.py          ← การแสดงผลและรายงาน
```

```python
# main.py - เรียกใช้จาก package
from src.pyshop.pricing import add_vat
from src.pyshop.inventory import find_products
from src.pyshop.report import print_table
```

```python
# src/pyshop/__init__.py - รวมของที่ใช้บ่อยไว้ให้เรียกสั้นลง
from .pricing import add_vat, apply_discount
from .inventory import find_products

__all__ = ["add_vat", "apply_discount", "find_products"]
```

> 💡 **โครงสร้าง src layout:** การวาง Package ไว้ใต้โฟลเดอร์ `src/` เป็นแนวปฏิบัติที่แนะนำในปัจจุบัน เพราะป้องกันไม่ให้ Python เผลอ import จากโฟลเดอร์ทำงานปัจจุบัน ทำให้มั่นใจว่าโค้ดที่ทดสอบคือโค้ดที่ติดตั้งจริง

### 6.6 คำสั่ง uv ที่ใช้บ่อย

| คำสั่ง | หน้าที่ | หมายเหตุ |
| --- | --- | --- |
| `uv add <ชื่อ>` | เพิ่มไลบรารีเข้าโปรเจกต์ | แก้ `pyproject.toml` + `uv.lock` ให้อัตโนมัติ |
| `uv add --dev <ชื่อ>` | เพิ่มไลบรารีสำหรับพัฒนาเท่านั้น | เช่น `pytest`, `ruff` ไม่ติดตั้งตอน Production |
| `uv remove <ชื่อ>` | ถอนไลบรารีออก | ล้างออกจากไฟล์ให้ด้วย |
| `uv sync` | ★ ติดตั้งทุกอย่างตาม `uv.lock` | คำสั่งที่เพื่อนร่วมทีมใช้ตอนรับโปรเจกต์ |
| `uv lock` | สร้าง/อัปเดตไฟล์ล็อกเวอร์ชัน | ปกติ `uv add` ทำให้แล้ว |
| `uv lock --upgrade` | อัปเกรดเวอร์ชันในล็อกไฟล์ | ทำเมื่อพร้อมทดสอบเท่านั้น |
| `uv tree` | ดูโครงสร้างไลบรารีแบบต้นไม้ | เห็นว่าใครพาใครมา |
| `uv run <ไฟล์>` | รันโปรแกรมในสภาพแวดล้อมโปรเจกต์ | ใช้ทุกวัน |
| `uv export -o requirements.txt` | ส่งออกเป็นรูปแบบเดิม | ใช้กับระบบเก่าที่ยังต้องการไฟล์นี้ |

หลังจาก `uv add requests rich` ไฟล์ `pyproject.toml` จะกลายเป็น:

```toml
[project]
name = "pyshop"
version = "0.1.0"
description = "PyShop Mini - ระบบจัดการสินค้าคงคลังร้านค้าขนาดเล็ก"
readme = "README.md"
requires-python = ">=3.13"
dependencies = [
    "requests>=2.32.3",
    "rich>=13.9.4",
]

[dependency-groups]
dev = [
    "pytest>=8.3.4",
    "ruff>=0.8.4",
]
```

### 6.7 pyproject.toml กับ uv.lock ต่างกันอย่างไร

นี่คือแนวคิดที่ผู้เรียนมักสับสน แต่สำคัญมากต่อการทำงานเป็นทีม


| --- | --- | --- |

```python
"""pricing.py - ตรรกะการคำนวณราคาและภาษีของ PyShop Mini"""

VAT_RATE = 0.07


def add_vat(amount: float, rate: float = VAT_RATE) -> float:
    """บวกภาษีมูลค่าเพิ่มเข้ากับยอดเงิน"""
    return amount * (1 + rate)


def vat_amount(amount: float, rate: float = VAT_RATE) -> float:
    """คืนเฉพาะจำนวนภาษีมูลค่าเพิ่ม"""
    return amount * rate


def apply_discount(price: float, percent: float) -> float:
    """คำนวณราคาหลังหักส่วนลดเป็นเปอร์เซ็นต์ (0-100)"""
    if not 0 <= percent <= 100:
        return price
    return price * (1 - percent / 100)


if __name__ == "__main__":
    assert add_vat(1000) == 1070.0
    assert apply_discount(1000, 10) == 900.0
    print("✅ pricing.py ทำงานถูกต้อง")
```

### ขั้นที่ 4 `src/pyshop/inventory.py` - ตรรกะคลังสินค้า

```python
"""inventory.py - ตรรกะการจัดการคลังสินค้าของ PyShop Mini"""

from .models import Product

LOW_STOCK_LIMIT = 10


def stock_value(product: Product) -> float:
    """คืนมูลค่าคงคลังของสินค้า 1 รายการ"""
    return product["price"] * product["stock"]


def total_value(products: list[Product]) -> float:
    """คืนมูลค่าคงคลังรวมของสินค้าทั้งหมด"""
    return sum(stock_value(p) for p in products)


def total_quantity(products: list[Product]) -> int:
    """คืนจำนวนชิ้นรวมของสินค้าทั้งหมด"""
    return sum(p["stock"] for p in products)


def stock_status(product: Product) -> str:
    """แปลจำนวนคงเหลือเป็นข้อความสถานะ"""
    stock = product["stock"]
    if stock <= 0:
        return "สินค้าหมด"
    if stock < LOW_STOCK_LIMIT:
        return "ใกล้หมด"
    return "ปกติ"


def find_by_code(products: list[Product], code: str) -> Product | None:
    """ค้นหาสินค้าจากรหัสแบบตรงตัว คืน None ถ้าไม่พบ"""
    target = code.strip().upper()
    for product in products:
        if product["code"] == target:
            return product
    return None


def search(products: list[Product], keyword: str) -> list[Product]:
    """ค้นหาสินค้าจากคำค้นหา (ตรวจทั้งรหัสและชื่อ)"""
    key = keyword.strip().lower()
    if not key:
        return list(products)
    return [
        p for p in products
        if key in p["name"].lower() or key in p["code"].lower()
    ]


def low_stock_items(products: list[Product]) -> list[Product]:
    """คืนรายการสินค้าที่ใกล้หมดหรือหมดแล้ว"""
    return [p for p in products if p["stock"] < LOW_STOCK_LIMIT]


def value_by_category(products: list[Product]) -> dict[str, float]:
    """สรุปมูลค่าคงคลังแยกตามหมวดหมู่"""
    summary: dict[str, float] = {}
    for product in products:
        category = product["category"]
        summary[category] = summary.get(category, 0.0) + stock_value(product)
    return summary
```

### ขั้นที่ 5 `src/pyshop/report.py` - การแสดงผล

```python
"""report.py - การแสดงผลและรายงานของ PyShop Mini"""

from .inventory import (
    stock_status,
    stock_value,
    total_quantity,
    total_value,
    value_by_category,
)
from .models import Product
from .pricing import add_vat, vat_amount

LINE_WIDTH = 70


def print_header(title: str) -> None:
    """พิมพ์หัวข้อพร้อมกรอบ"""
    print("\n" + "=" * LINE_WIDTH)
    print(f"  {title}")
    print("=" * LINE_WIDTH)


def print_table(products: list[Product], title: str = "รายการสินค้า") -> None:
    """แสดงตารางสินค้าพร้อมยอดสรุป"""
    print_header(title)

    if not products:
        print("  - ไม่พบข้อมูลสินค้า -")
        return

    print(
        f"{'รหัส':<10}{'ชื่อสินค้า':<18}{'ราคา':>10}"
        f"{'คงเหลือ':>9}{'มูลค่า':>13}  สถานะ"
    )
    print("-" * LINE_WIDTH)

    for product in products:
        print(
            f"{product['code']:<10}{product['name']:<18}"
            f"{product['price']:>10,.0f}{product['stock']:>9}"
            f"{stock_value(product):>13,.0f}  {stock_status(product)}"
        )

    print("-" * LINE_WIDTH)
    print(f"รวม {len(products)} รายการ  {total_quantity(products):>28,} ชิ้น"
          f"{total_value(products):>13,.0f}")


def print_summary(products: list[Product]) -> None:
    """แสดงรายงานสรุปภาพรวมคลังสินค้า"""
    print_header("📊 สรุปภาพรวมคลังสินค้า")

    if not products:
        print("  - ยังไม่มีสินค้าในระบบ -")
        return

    value = total_value(products)
    print(f"  จำนวนรายการ       : {len(products):>15,} รายการ")
    print(f"  จำนวนชิ้นรวม       : {total_quantity(products):>15,} ชิ้น")
    print(f"  มูลค่าคลัง (ก่อน VAT): {value:>15,.2f} บาท")
    print(f"  VAT 7%             : {vat_amount(value):>15,.2f} บาท")
    print(f"  มูลค่ารวม (มี VAT)  : {add_vat(value):>15,.2f} บาท")

    print("\n  มูลค่าแยกตามหมวดหมู่:")
    summary = value_by_category(products)
    for category, amount in sorted(summary.items(), key=lambda x: x[1], reverse=True):
        share = amount / value * 100 if value else 0
        bar = "█" * int(share / 4)
        print(f"    {category:<14}{amount:>12,.0f} บาท  {share:>5.1f}%  {bar}")
```

### ขั้นที่ 6 `main.py` - เมนูหลัก

```python
"""main.py - PyShop Mini v1 (Python Basic 2026 - Workshop Day 1)"""

from src.pyshop.inventory import find_by_code, low_stock_items, search
from src.pyshop.models import create_product, sample_inventory
from src.pyshop.report import print_header, print_summary, print_table

MENU = """
╔══════════════════════════════════════════╗
║        PyShop Mini v1 - เมนูหลัก          ║
╠══════════════════════════════════════════╣
║  1. แสดงรายการสินค้าทั้งหมด                ║
║  2. ค้นหาสินค้า                           ║
║  3. เพิ่มสินค้าใหม่                        ║
║  4. ปรับจำนวนคงเหลือ                      ║
║  5. รายการที่ต้องสั่งเพิ่ม                  ║
║  6. รายงานสรุปภาพรวม                     ║
║  0. ออกจากโปรแกรม                        ║
╚══════════════════════════════════════════╝
"""


def ask_int(prompt: str, default: int = 0) -> int:
    """รับตัวเลขจำนวนเต็มจากผู้ใช้ ถ้าใส่ผิดจะคืนค่าเริ่มต้น"""
    text = input(prompt).strip()
    if text.lstrip("-").isdigit():
        return int(text)
    print("  ⚠ ค่าที่ใส่ไม่ใช่จำนวนเต็ม ใช้ค่าเริ่มต้นแทน")
    return default


def ask_float(prompt: str, default: float = 0.0) -> float:
    """รับตัวเลขทศนิยมจากผู้ใช้ ถ้าใส่ผิดจะคืนค่าเริ่มต้น"""
    text = input(prompt).strip()
    try:
        return float(text)
    except ValueError:
        print("  ⚠ ค่าที่ใส่ไม่ใช่ตัวเลข ใช้ค่าเริ่มต้นแทน")
        return default


def action_add(inventory: list) -> None:
    """เพิ่มสินค้าใหม่เข้าคลัง"""
    print_header("➕ เพิ่มสินค้าใหม่")
    code = input("รหัสสินค้า : ").strip()

    if find_by_code(inventory, code):
        print(f"  ⚠ รหัส {code.upper()} มีอยู่แล้วในระบบ")
        return

    name = input("ชื่อสินค้า  : ").strip()
    if not code or not name:
        print("  ⚠ ต้องระบุทั้งรหัสและชื่อสินค้า")
        return

    price = ask_float("ราคา       : ")
    stock = ask_int("จำนวน      : ")
    category = input("หมวดหมู่    : ").strip()

    inventory.append(create_product(code, name, price, stock, category))
    print(f"  ✅ เพิ่ม {name} เรียบร้อยแล้ว (ทั้งหมด {len(inventory)} รายการ)")


def action_adjust(inventory: list) -> None:
    """ปรับจำนวนคงเหลือของสินค้า"""
    print_header("🔄 ปรับจำนวนคงเหลือ")
    code = input("รหัสสินค้า : ").strip()
    product = find_by_code(inventory, code)

    if product is None:
        print(f"  ⚠ ไม่พบสินค้ารหัส {code.upper()}")
        return

    print(f"  สินค้า: {product['name']} (คงเหลือปัจจุบัน {product['stock']} ชิ้น)")
    change = ask_int("เปลี่ยนแปลง (+เพิ่ม / -ลด): ")
    new_stock = product["stock"] + change

    if new_stock < 0:
        print(f"  ⚠ ลดไม่ได้ เพราะจะเหลือ {new_stock} ชิ้น")
        return

    product["stock"] = new_stock
    print(f"  ✅ ปรับเรียบร้อย คงเหลือใหม่ {new_stock} ชิ้น")


def main() -> None:
    inventory = sample_inventory()

    while True:
        print(MENU)
        choice = input("เลือกเมนู: ").strip()

        match choice:
            case "1":
                print_table(inventory, "📦 สินค้าทั้งหมด")
            case "2":
                keyword = input("คำค้นหา: ")
                print_table(search(inventory, keyword), f"🔍 ผลการค้นหา '{keyword}'")
            case "3":
                action_add(inventory)
            case "4":
                action_adjust(inventory)
            case "5":
                print_table(low_stock_items(inventory), "⚠️  ต้องสั่งเพิ่ม")
            case "6":
                print_summary(inventory)
            case "0":
                print("\n👋 ขอบคุณที่ใช้งาน PyShop Mini แล้วพบกันวันพรุ่งนี้ครับ")
                break
            case _:
                print("  ⚠ ไม่มีเมนูนี้ กรุณาเลือก 0-6")


if __name__ == "__main__":
    main()
```

> ✅ **ผลลัพธ์ที่คาดหวัง:** เห็นเมนูกรอบสวยงาม แล้วทดสอบครบทั้ง 6 เมนู โดยเฉพาะ
>
> - เมนู 1 แสดงสินค้า 5 รายการพร้อมสถานะและมูลค่ารวม
> - เมนู 3 เพิ่มสินค้าใหม่แล้วกลับไปดูเมนู 1 ต้องเห็นรายการเพิ่มขึ้น
> - เมนู 4 ปรับจำนวนแล้วสถานะต้องเปลี่ยนตาม (เช่น ลดคีย์บอร์ดจาก 8 เหลือ 0 จะกลายเป็น "สินค้าหมด")
> - เมนู 6 แสดงกราฟแท่งสัดส่วนมูลค่าแยกตามหมวด
>
> ⛔ **ถ้าเจอ `ModuleNotFoundError: No module named 'src'`** ให้ตรวจว่ารันจากโฟลเดอร์ `pyshop` (โฟลเดอร์ที่มี `main.py`) ไม่ใช่จากโฟลเดอร์อื่น และมีไฟล์ `src/pyshop/__init__.py` ครบแล้ว

> 🏁 **ข้อสังเกตสำคัญของ Workshop นี้:** สังเกตว่า `main.py` แทบไม่มีตรรกะการคำนวณเลย มีแต่การรับคำสั่งจากผู้ใช้แล้วเรียกฟังก์ชันจากโมดูลอื่น นี่คือแนวคิด **แยกส่วนติดต่อผู้ใช้ (UI) ออกจากตรรกะทางธุรกิจ (Logic)** ซึ่งทำให้วันพรุ่งนี้เราเปลี่ยนหน้าจอเป็น GUI ได้โดยแทบไม่ต้องแก้ไฟล์ใน `src/pyshop/` เลย
