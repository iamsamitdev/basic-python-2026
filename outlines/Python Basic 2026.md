Python นับเป็นภาษาที่มีความสำคัญเป็นอย่างยิ่งในยุคปัจจุบัน ด้วยความสามารถของตัวภาษาที่มีความหลากหลายครอบคลุม ไม่ว่าจะเป็นการนำมาพัฒนา Web Application, Desktop Application, IoT, Data Analytics, AI และ Machine Learning จึงเป็นภาษาที่มีความต้องการในตลาดการพัฒนาซอฟต์แวร์อย่างสูงต่อเนื่องมาโดยตลอด ตัวภาษาเองเหมาะสำหรับผู้เริ่มต้นในสายงานการเขียนโปรแกรม รูปแบบภาษาทำความเข้าใจง่าย เรียนรู้ได้เร็ว จึงถูกนำมาใช้ในการเรียนการสอนในสถาบันการศึกษาทั่วไป

ในหลักสูตรนี้จะเป็นการปูพื้นฐานให้กับผู้เริ่มต้นในสายงานโปรแกรมมิ่ง ผู้เข้าอบรมจะได้เรียนรู้โครงสร้างของภาษาอย่างถูกต้อง รวดเร็ว และนำไปปรับใช้ได้ทันที เนื้อหาฉบับปี 2026 ได้ปรับปรุงให้สอดคล้องกับเครื่องมือและแนวปฏิบัติที่ใช้งานจริงในปัจจุบัน โดยใช้ **uv** ซึ่งเป็นเครื่องมือจัดการเวอร์ชัน Python สภาพแวดล้อม และแพ็กเกจยุคใหม่ที่ทำงานได้รวดเร็วกว่าเครื่องมือแบบเดิมมาก เป็นเครื่องมือหลักตลอดหลักสูตร ควบคู่กับการใช้ Visual Studio Code และ PyCharm การเขียนโค้ดสไตล์สมัยใหม่ด้วย f-string และ Type Hints รวมถึงการใช้ AI Coding Assistant เป็นผู้ช่วยในการเรียนรู้อย่างเหมาะสม

ดำเนินการสอนโดยวิทยากรผู้มีความเชี่ยวชาญและมีผลงานการพัฒนาโปรแกรมมิ่งมาอย่างยาวนาน ผู้เรียนจะสามารถเก็บเกี่ยวประสบการณ์จากผู้สอน และได้แนวทางแนวคิดที่ถูกต้องในการพัฒนาโปรแกรมด้วยภาษา Python เพื่อนำไปต่อยอดในงานต่อไป

## วัตถุประสงค์ของหลักสูตร

- เพื่อให้เข้าใจภาษา Python ตั้งแต่เริ่มต้นอย่างเป็นระบบ
- เข้าใจโครงสร้างและไวยากรณ์ของภาษาได้อย่างถ่องแท้
- ติดตั้งและจัดการสภาพแวดล้อมการพัฒนา (Python, Virtual Environment, Editor) ด้วย uv ได้ด้วยตนเอง
- เขียนโปรแกรมด้วยตัวแปร ชนิดข้อมูล เงื่อนไข และการทำซ้ำได้อย่างถูกต้อง
- ใช้งานชนิดข้อมูลแบบกลุ่ม (List, Tuple, Set, Dictionary) ในการแก้ปัญหาได้
- สร้างและเรียกใช้ฟังก์ชันเพื่อจัดระเบียบโค้ดให้นำกลับมาใช้ซ้ำได้
- เข้าใจการใช้งาน Module และ Package รวมถึงการติดตั้งและจัดการไลบรารีจากภายนอกด้วย uv
- จัดการไฟล์ข้อมูล (Text, CSV, JSON) ด้วย Python ได้
- เขียนโปรแกรมเชิงวัตถุ (OOP) ด้วยภาษา Python ได้
- จัดการข้อผิดพลาดของโปรแกรม (Exception Handling) และ Debug ได้อย่างเป็นระบบ
- เชื่อมต่อและจัดการข้อมูลกับฐานข้อมูล MySQL หรือ PostgreSQL ด้วย Python ได้
- ใช้งาน Git เพื่อบริหารจัดการเวอร์ชันของโค้ดและทำงานร่วมกับผู้อื่นได้
- สร้างโปรแกรมแบบ GUI เบื้องต้นด้วย Python ได้
- เรียนรู้แนวทางการนำ Python ไปประยุกต์ใช้ในงานจริง ทั้งงานคำนวณ งานอัตโนมัติ และ Web Application

## เครื่องมือและเทคโนโลยีที่ใช้ในหลักสูตร

- **uv (เครื่องมือหลักของหลักสูตร)**: จัดการเวอร์ชัน Python, Virtual Environment, การติดตั้งแพ็กเกจ และการรันโปรเจกต์แบบครบวงจรในเครื่องมือเดียว
- **Python 3.13 / 3.14 (เวอร์ชันเสถียรล่าสุด)**: ภาษาหลักที่ใช้ตลอดหลักสูตร ติดตั้งและสลับเวอร์ชันผ่าน uv
- **Visual Studio Code + Python Extension**: Editor หลักที่แนะนำสำหรับผู้เริ่มต้น
- **PyCharm Community Edition**: IDE ทางเลือกสำหรับงานพัฒนาโปรเจกต์ขนาดใหญ่
- **pyproject.toml และ uv.lock**: ไฟล์มาตรฐานสำหรับกำหนดและตรึงเวอร์ชันไลบรารีของโปรเจกต์
- **PyPI**: แหล่งรวมไลบรารีจากภายนอก (เข้าถึงผ่านคำสั่ง uv add)
- **pip และ venv**: เรียนรู้ในฐานะเครื่องมือดั้งเดิม เพื่อให้เข้าใจโค้ดและเอกสารเก่าที่ยังพบได้ทั่วไป
- **MySQL หรือ PostgreSQL**: ฐานข้อมูลสำหรับ Workshop การเชื่อมต่อข้อมูล
- **Git และ GitHub**: ระบบบริหารจัดการเวอร์ชันของซอร์สโค้ด
- **Tkinter / CustomTkinter**: ไลบรารีสำหรับสร้าง GUI เบื้องต้น
- **AI Coding Assistant (เช่น GitHub Copilot หรือ Claude)**: แนวทางการใช้ AI เป็นผู้ช่วยเรียนรู้อย่างเหมาะสม

**Module 1 แนะนำภาษา Python (Overview)**

- ทำไมภาษา Python ถึงเหมาะกับการเริ่มต้นเขียนโปรแกรม
- คุณสมบัติเด่นและข้อจำกัดของภาษา Python
- ภาพรวมการนำ Python ไปใช้งานจริง: Web, Automation, Data, AI และ Machine Learning
- ตลาดแรงงานและเส้นทางอาชีพของนักพัฒนา Python ในปี 2026
- ภาพรวมเวอร์ชันของ Python และความแตกต่างที่ควรทราบ

**Module 2 การเตรียมเครื่องมือและสภาพแวดล้อมด้วย uv**

- รู้จัก uv: เครื่องมือจัดการ Python ยุคใหม่ และเหตุผลที่หลักสูตรเลือกใช้แทน pip แบบเดิม
- การติดตั้ง uv ลงเครื่องคอมพิวเตอร์ผู้เรียน (Windows / macOS / Linux)
- การเลือกและติดตั้งเวอร์ชันของ Python ด้วยคำสั่ง `uv python install` และ `uv python list`
- การติดตั้ง Python หลายเวอร์ชันในเครื่องเดียวกันและการสลับใช้งานด้วย uv
- การสร้างโปรเจกต์ใหม่ด้วย `uv init` และทำความรู้จักไฟล์ pyproject.toml
- การสร้างและใช้งาน Virtual Environment ด้วย `uv venv` (พร้อมเปรียบเทียบกับ venv แบบดั้งเดิม)
- การติดตั้งเครื่องมือสำหรับการเขียนโปรแกรม (Editor) ด้วย Visual Studio Code และ PyCharm
- การตั้งค่าและ Configuration เครื่องมือก่อนเริ่มใช้งาน (Extension, การชี้ Interpreter ไปยัง .venv ของ uv, Formatter)
- การรันโปรแกรมด้วย `uv run` ผ่าน Terminal และผ่าน Editor
- **Workshop**: ติดตั้ง uv สร้างโปรเจกต์แรก และรันโปรแกรม Hello World ด้วย `uv run`

**Module 3 พื้นฐานภาษา Python**

- โครงสร้างการเขียนโปรแกรมภาษาไพธอนและกฎการย่อหน้า (Indentation)
- ตัวแปร การกำหนดค่า และชนิดข้อมูลพื้นฐาน (int, float, str, bool)
- การรับค่าจากผู้ใช้และการแสดงผลด้วย f-string
- นิพจน์ ตัวดำเนินการ และตัวถูกดำเนินการ
- เงื่อนไข การตัดสินใจ และการควบคุมทิศทาง (if / elif / else, match-case)
- การทำซ้ำด้วย for และ while รวมถึง break และ continue
- การเขียน Comment และแนวทางการตั้งชื่อตามมาตรฐาน PEP 8
- **Workshop**: เขียนโปรแกรมคำนวณและโปรแกรมตรวจสอบเงื่อนไขอย่างง่าย

**Module 4 ชนิดข้อมูลแบบกลุ่ม (Collections)**

- List: การสร้าง เข้าถึง เพิ่ม ลบ และการ Slice ข้อมูล
- Tuple และความแตกต่างจาก List
- Set และการดำเนินการทางเซต
- Dictionary: การจัดเก็บข้อมูลแบบ Key-Value และการวนลูปอ่านข้อมูล
- การใช้งาน List Comprehension เพื่อเขียนโค้ดให้กระชับ
- **Workshop**: จัดการชุดข้อมูลรายการสินค้าและสรุปผลด้วย Collections

**Module 5 รู้จักฟังก์ชัน (Function) และการสร้างฟังก์ชันใช้งาน**

- แนวทางการสร้างฟังก์ชันในภาษา Python
- รูปแบบการสร้างฟังก์ชันที่มีการรับค่าแบบต่าง ๆ (Positional, Keyword, Default, \*args, \*\*kwargs)
- การคืนค่าจากฟังก์ชันและการนำฟังก์ชันไปใช้งาน
- การกำหนดขอบเขตของตัวแปรในฟังก์ชัน (Local / Global Scope)
- การเขียน Docstring และการใช้ Type Hints เพื่อให้โค้ดอ่านง่ายและตรวจสอบได้
- แนะนำ Lambda Function เบื้องต้น
- **Workshop**: แปลงโค้ดที่เขียนซ้ำให้เป็นฟังก์ชันที่นำกลับมาใช้ใหม่ได้

**Module 6 โมดูลและแพ็คเกจ (Modules and Packages) ใน Python**

- แนะนำการสร้างโมดูล (Module) ใน Python เบื้องต้น
- การเรียกใช้งานโมดูลใน Python แบบต่าง ๆ (import, from-import, as)
- แพ็คเกจ (Packages) และการจัดโครงสร้างโปรเจกต์
- โมดูลมาตรฐานที่ควรรู้จัก (os, sys, datetime, math, random, json)
- การนำ Package จากภายนอกมาใช้งานร่วมด้วย ผ่าน uv และ PyPI
- คำสั่งที่ใช้บ่อย: `uv add`, `uv remove`, `uv sync`, `uv lock` และ `uv tree`
- การจัดการรายการไลบรารีด้วย pyproject.toml และการตรึงเวอร์ชันด้วย uv.lock
- การแยกไลบรารีสำหรับพัฒนาออกจากไลบรารีที่ใช้จริง (`uv add --dev`)
- การส่งต่อโปรเจกต์ให้เพื่อนร่วมทีมติดตั้งซ้ำได้เหมือนกันทุกเครื่องด้วย `uv sync`
- การทำงานร่วมกับ requirements.txt แบบเดิม (`uv pip install -r`, `uv export`) สำหรับโปรเจกต์เก่า
- **Workshop**: เพิ่มไลบรารีภายนอกเข้าโปรเจกต์ด้วย uv แล้วเรียกใช้งานจริง พร้อมทดสอบ `uv sync` บนเครื่องเพื่อน
